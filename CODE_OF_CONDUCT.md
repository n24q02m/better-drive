# Code of Conduct

The better-drive project is committed to providing a welcoming, respectful,
and harassment-free community for everyone who participates in the project.

## Expected behavior

- Be respectful and constructive.
- Assume good intent while discussing technical disagreements.
- Focus feedback on the work, not on the person.
- Protect other people's privacy and confidential information.

## Unacceptable behavior

Harassment, discrimination, personal attacks, threats, doxxing, sexualized
attention without consent, and publishing private information are not
acceptable. Deliberately disrupting project collaboration or abusing project
resources is also not acceptable.

## Enforcement

For a non-sensitive conduct concern, open a GitHub issue with only the
information needed for the maintainers to investigate. For a sensitive report,
use the repository's [private security advisory form](https://github.com/n24q02m/better-drive/security/advisories/new)
and state that it is a conduct report. Reports will be reviewed promptly and
handled as confidentially as the circumstances allow.

Retaliation against anyone who raises a concern in good faith is not allowed.

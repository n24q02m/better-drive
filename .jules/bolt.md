## 2024-05-24 - Pre-allocating Slices and Zero-Allocation Indexing
**Learning:** Pre-allocating slice capacities (e.g., `make([]string, 0, len(lines))`) is crucial in high-volume operations like `TranslateIgnoreLines` to prevent hidden re-allocations during `append`. When checking single characters, zero-allocation byte indexing (e.g., `line[0] == '#'`) is significantly faster than function calls like `strings.HasPrefix`, provided you safely check for empty strings first. It's also important to check for nil slices properly, checking if `len(slice) == 0` instead of just `slice == nil` when expecting to return `nil`.
**Action:** Always look for loops where slices are built using `append` and pre-allocate if the final size is known or bounded. Replace `strings.HasPrefix` with byte index checks for single characters in tight loops, ensuring safety bounds are checked beforehand.

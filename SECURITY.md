# Security Policy

## Supported versions

The `main` branch is the supported development line. Published releases are
supported according to the release notes for that version.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue or pull
request. Use GitHub's private vulnerability reporting form for
[better-drive](https://github.com/n24q02m/better-drive/security/advisories/new).
The repository [Security page](https://github.com/n24q02m/better-drive/security)
is also available if the private form is not shown for your account.

Include the affected version or commit, the operating system, clear
reproduction steps, and any relevant logs or proof of concept. Remove
credentials and other sensitive data before submitting a report.

## Response and disclosure timeline

We aim to acknowledge a vulnerability report within 7 calendar days and to
provide an initial assessment within 14 calendar days. We will coordinate a
fix and disclosure timeline with the reporter; a complex vulnerability may
require more than 30 days to remediate safely.

Please allow time for investigation and coordinated disclosure before sharing
details publicly. We will credit reporters who want attribution in the fix or
release notes.
